# US-11 — Ver portfolio

> Como usuario, quiero ver el estado actual de mi portfolio,
> para conocer el valor total de mi cartera.

**Criterios de aceptación:**
- Se listan todas las posiciones activas con ticker, cantidad, precio actual y valor total por posición.
- Se muestra el valor total del portfolio (suma de todas las posiciones).
- El precio usado es el último almacenado por el batch, con su fecha de actualización.
- Si el portfolio está vacío, se indica con un mensaje.
