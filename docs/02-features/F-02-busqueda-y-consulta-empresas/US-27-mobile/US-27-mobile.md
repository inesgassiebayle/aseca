# US-27 — [Mobile] Búsqueda y consulta de empresas desde la app móvil

>
> Como usuario mobile, quiero buscar empresas y ver sus datos financieros desde la app móvil,
> para consultar información en cualquier momento.

**Criterios de aceptación:**
- Las funcionalidades de búsqueda (US-03), detalle (US-04), filings (US-05) y evolución (US-06) están disponibles en mobile.
- Se implementan tests de Appium que cubren búsqueda por ticker, visualización de métricas y navegación entre vistas.
