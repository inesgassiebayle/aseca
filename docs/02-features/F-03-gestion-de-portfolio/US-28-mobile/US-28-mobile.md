# US-28 — [Mobile] Gestión de portfolio desde la app móvil

>
> Como usuario mobile, quiero registrar operaciones y ver mi portfolio con P&L desde la app móvil,
> para gestionar mis inversiones desde cualquier lugar.

**Criterios de aceptación:**
- Las funcionalidades de compra/venta (US-08, US-09), historial (US-10), portfolio (US-11, US-12) y P&L (US-19, US-20) están disponibles en mobile.
- Se implementan tests de Appium que cubren compra, venta y visualización del portfolio con P&L.
