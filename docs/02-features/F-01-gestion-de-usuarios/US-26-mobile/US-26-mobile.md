# US-26 — [Mobile] Registro y login desde la app móvil

>
> Como usuario mobile, quiero poder registrarme e iniciar sesión desde la app móvil,
> para acceder al sistema desde mi dispositivo.

**Criterios de aceptación:**
- El flujo de registro y login es equivalente al de la web.
- Se implementan tests de Appium que cubren registro exitoso, login exitoso y errores de validación.
