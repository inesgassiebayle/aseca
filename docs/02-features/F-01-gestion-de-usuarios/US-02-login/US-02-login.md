### US-02 — Login
> Como usuario registrado, quiero iniciar sesión con mis credenciales,
> para acceder a mi perfil en el sistema.

**Criterios de aceptación:**
- Las credenciales incorrectas retornan un error 401.
- El login exitoso retorna un token válido.
- El token debe incluirse en cada request subsiguiente.
